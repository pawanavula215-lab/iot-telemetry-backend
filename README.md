# IoT Telemetry Backend

A sample backend for ingesting and retrieving IoT device telemetry data using REST and GraphQL APIs.

### ⚙️ Tech Stack
- Java 17 / Spring Boot
- PostgreSQL
- GraphQL
- Docker & GitHub Actions (CI/CD)
- AWS IoT Core (conceptual integration)

### 📡 API Endpoints
**GET /api/sensors/latest**
Returns the latest telemetry readings for a device.

**POST /api/sensors**
Accepts incoming sensor data in JSON format.

### 🧠 Features
- Device telemetry ingestion (simulated)
- REST & GraphQL endpoints
- CI/CD pipeline demo
- Dockerized for local testing
